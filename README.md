# 🤖 CYBORG — Futuristic Landing Page

A modern, cyberpunk-inspired landing page designed around futuristic technology, cybernetic evolution, and human-machine interaction.

## ✨ Features

* Futuristic dark theme with neon cyan and purple accents
* Stylish CYBORG branding and navigation bar
* Hero section with futuristic robot imagery
* Animated visual elements and glowing effects
* Interactive hover effects on buttons and feature cards
* About and Features sections
* Responsive layout for desktop, tablet, and mobile screens
* Mobile navigation menu

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Unsplash for imagery

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Explore the landing page.

## 📁 Project Structure

```text
cyborg-landing-page/
├── index.html
├── style.css
└── script.js
```

## 🎯 Project Objective

The objective of this project is to develop a visually engaging, futuristic landing page using core frontend technologies, focusing on modern UI design, responsive layouts, CSS animations, and interactive elements.
